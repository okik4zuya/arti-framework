## Next step for the researcher

This run used a demo researcher profile and a demo voice profile. To work on a real paper, replace them: delete
`~/.arti/memory/researcher-profile.md` and run ARTi-setup (profile interview), then ARTi-writing Stage 0 (voice profile).
In Word, open the manuscript with the Zotero plugin and press Refresh to re-format every citation in any journal style.
