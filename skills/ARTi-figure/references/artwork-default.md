# Artwork default

One default set that most journals accept. Used by ARTi-figure verification when the project has no
Journal Profile. It is not a step of ARTi-SLR, and journal-specific rules apply only when the
researcher asks for them.

| Item | Default | Basis |
|---|---|---|
| Width | 1 column ~85-90 mm; 2 columns ~170-190 mm | Common publisher practice (Elsevier's 90/140/190 mm confirmed in the Stage 4 session) |
| Final text size | 7 pt minimum at print width | Common publisher practice |
| Font | Arial or Helvetica | Elsevier verified; common elsewhere |
| Line weight | 0.5 pt minimum | Common publisher practice |
| Primary format | Vector PDF with fonts embedded | Common publisher practice |
| Raster resolution | 1000 dpi line art, 500 dpi combination, 300 dpi halftone | Elsevier verified (2026-10-01 session) |

**Verified:** only the Elsevier figures marked above, checked in the 2026-10-01 SnO2 SLR session.
**Common practice, not verified per publisher:** everything else. Re-check against the journal's
author guide only if the researcher asks.

Always check font size at print width: a 20 px label on an 850 px canvas scaled to 90 mm is about
5.2 pt, below the 7 pt minimum.
