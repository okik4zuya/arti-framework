# Manuscript Drafting — Progress Tracker (template)

> Per-section checkpoint tracker — the single source of truth for "which manuscript section is
> drafted, at what word count, with what still open" so this never requires re-deriving status from
> the Manuscript file's own header or from `memory\todo-list.md`. Read first when resuming
> drafting. Update in the same turn a section is drafted or revised — one section touched = one row
> edit, never deferred to session end.

**Section list reference:** this project's `writing\manuscript-blueprint.md`

| Section | Status | Draft # last touched | Word count | Date | Open flags (count/summary) |
|---|---|---|---|---|---|
| | ⬜ | | | | |

**Status vocabulary (exhaustive — no row may be ambiguous):**
- ⬜ not drafted
- 🔶 drafted, open flags remain
- ✅ drafted, no open flags
- 🔁 revised since last Iteration Log entry
