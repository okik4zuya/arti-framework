# Manuscript Self-Review Checklist

Use this checklist after completing each draft iteration, before filling Section 5 of the Iteration Log.
Check each item and note any issues found.

---

## A. Journal Compliance
- [ ] Article type matches what the journal accepts
- [ ] Manuscript structure matches journal requirements
- [ ] Word count is within limits (overall and per section)
- [ ] Abstract format and word limit met
- [ ] Number of figures/tables within journal limits
- [ ] Reference style matches journal exactly
- [ ] Keywords meet journal requirements

---

## B. Title & Abstract
- [ ] Title is concise, specific, and reflects the key finding
- [ ] Abstract covers: background, objective, methods, results, conclusion
- [ ] No citations or undefined abbreviations in abstract
- [ ] Abstract can stand alone as a summary of the paper

---

## C. Introduction
- [ ] Opens with broad context, narrows to specific gap
- [ ] Research gap is clearly identified
- [ ] Objective/novelty is explicitly stated
- [ ] Literature is recent and relevant
- [ ] Logical flow from general → specific → objective

---

## D. Materials & Methods
- [ ] All materials are identified with source/purity
- [ ] All instruments cited with model and manufacturer
- [ ] Methods are reproducible as written
- [ ] No results appear in this section

---

## E. Results (or Results & Discussion)
- [ ] Every figure and table is cited in the text
- [ ] Figures and tables have complete captions
- [ ] Data is presented in logical order
- [ ] Past tense used consistently
- [ ] No unsupported interpretations (in Results-only section)

---

## F. Discussion
- [ ] Each result is interpreted, not just restated
- [ ] Comparison with literature is specific (not vague)
- [ ] All `[⚠️ CONTRADICTION]` flags from Scratchbook have been addressed and synthesized
- [ ] Unexpected results are addressed
- [ ] Limitations are acknowledged
- [ ] Findings connect back to the stated objective

---

## G. Conclusion
- [ ] Key findings are summarized (not copied from abstract)
- [ ] Contribution/significance is clearly stated
- [ ] Future work suggested
- [ ] No new data or citations introduced

---

## H. Overall Quality
- [ ] Writing is clear, concise, and precise throughout
- [ ] No undefined abbreviations on first use
- [ ] Consistent terminology across all sections
- [ ] No grammatical or typographical errors
- [ ] Logical flow between sections (Introduction → Methods → Results → Discussion → Conclusion)
- [ ] All claims are supported by data or citations

---

## I. Plagiarism Integrity
- [ ] All literature is paraphrased — no direct quotes from source papers
- [ ] No sentence structure mimics the original source even if words differ
- [ ] Every in-text citation has a corresponding entry in the Reference List
- [ ] Every Reference List entry is cited at least once in the text
- [ ] Methods section is freshly written — not reused from a prior paper (self-plagiarism check)
- [ ] Introduction does not reproduce phrasing from review articles or prior work
- [ ] Figures and tables from other sources have explicit permission and attribution
- [ ] No `[SOURCE NEEDED]` tags remain unresolved in the Scratchbook or manuscript
- [ ] Draft has been run through a plagiarism checker (iThenticate / Turnitin / Copyleaks)
- [ ] AI-generated sections have been reviewed, personalized, and verified by the author before submission

---

## J. Hallucination & Citation Integrity
- [ ] Every citation in the manuscript is traceable to an entry in the Scratchbook `## Reference List`
- [ ] No `[CITATION NEEDED]` tags remain unresolved
- [ ] No `[DATA NEEDED — VERIFY FROM SOURCE]` tags remain unresolved
- [ ] No `[UNVERIFIED — USER MUST CONFIRM]` tags remain unresolved in the Reference List
- [ ] All numerical values (e.g., peak positions, efficiencies, yields) are verified against original data or source paper
- [ ] Author names, journal names, years, volume, page numbers, and DOIs of all references have been manually verified
- [ ] No citation has been accepted solely on Claude's suggestion without the user confirming the actual source

---

## K. Scratchbook Tag Integrity
- [ ] All `[⚠️ CONTRADICTION]` tags have been resolved or addressed in the Discussion
- [ ] All `[CONNECTION]` tags have been reviewed — relevant insights carried into the manuscript
- [ ] All `[SOURCE NEEDED]` tags have been resolved
- [ ] `## Unassigned Literature` section in Scratchbook is empty — all references placed in a section
- [ ] `## Reference List` in Scratchbook is complete and matches all inline `[LIT: Author, Year]` tags

---

## Iteration Log Hand-Off

After completing the checklist, carry the result into this draft's Iteration Log entry
(`writing\iteration-log.md`) — the checklist does not get its own file:

- Anything failed above becomes a ranked item in **Section 4 — Priority Action List**
- Once fixed, the fix is recorded in **Section 5 — Actions Taken / Deliberately Deferred**
  of that same entry, with what was changed and where
- Tags still open and issues not resolved go in Section 5 under *Deliberately deferred* and
  *Carried forward to the next iteration*
- Record the feedback source (self-review / supervisor / co-author / peer reviewer) at the top
  of the entry

---

## L. Writing Style Compliance
- [ ] Title matches the journal's structural pattern (from Block B)
- [ ] Abstract follows the identified sentence structure, tense, and voice pattern
- [ ] Voice and hedging language consistent with journal style throughout
- [ ] Section lengths and depth proportional to journal norms
- [ ] In-text citation style matches journal preference
- [ ] Terminology and chemical name conventions consistent with journal practice

---

## M. Technical Depth Compliance
- [ ] All characterization techniques expected by this journal are present (Block C)
- [ ] Data reporting standards met — error bars, reproducibility where expected
- [ ] Discussion depth matches journal benchmark — not merely descriptive
- [ ] All major claims are supported by sufficient evidence — no overclaiming
- [ ] No collected data is left underutilized or undiscussed
- [ ] State-of-the-art benchmarking included if expected by this journal
- [ ] Mechanism or explanation depth matches journal expectation
